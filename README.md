# 🎓 Repositório de Objetos ABAP - Bootcamp SAP S/4HANA

Este repositório é um portfólio de objetos de desenvolvimento ABAP criados durante o **Bootcamp SAP S/4HANA**, uma iniciativa promovida pela **T-Systems & Ready Proway**.

Ele serve como um registro prático dos conhecimentos adquiridos em programação ABAP, Dicionário de Dados (DDIC) e desenvolvimento de aplicações.

## ✨ Destaques do Conteúdo

O repositório inclui uma variedade de objetos essenciais para o desenvolvimento ABAP:

- **Programas e Reports:** Lógica de aplicação e relatórios.
- **Includes:** Componentes de código reutilizáveis, organizados junto aos seus programas principais.
- **Dicionário de Dados (DDIC):** Definições de Domínios, Elementos de Dados, Tabelas e Estruturas.
- **Transações:** Pontos de acesso para execução dos programas.
- **Grupos de Função:** Estruturas para encapsulamento de módulos de função.

## 🚀 Pronto para abapGit

A estrutura de pastas foi cuidadosamente organizada seguindo o padrão de serialização do **abapGit**. Isso garante que todos os objetos possam ser clonados e importados de forma rápida e eficiente em qualquer sistema SAP.

## 📂 Estrutura de Pastas

A organização segue a separação por tipo de objeto ABAP:

| Pasta                 | Conteúdo                                                                    |
| :-------------------- | :-------------------------------------------------------------------------- |
| `Dominios/`           | Objetos DDIC do tipo Domínio (`.doma.xml` )                                 |
| `Elementos_de_Dados/` | Objetos DDIC do tipo Elemento de Dados (`.dtel.xml`)                        |
| `Tabelas/`            | Objetos DDIC do tipo Tabela/Estrutura (`.tabl.xml`)                         |
| `Transacoes/`         | Objetos do tipo Transação (`.tran.xml`)                                     |
| `Function_Groups/`    | Grupos de Função (`.fugr`)                                                  |
| `Programas_Reports/`  | Programas Executáveis e Módulos de Função (Includes aninhados em subpastas) |
| **Raiz**              | Arquivos de configuração: `.abapgit.xml` e `package.devc.xml`               |
